# Celular bot (Instagram) · 2026-11-25 10:12

**Entregable:**  
Script en Python para automatizar tareas en Instagram desde el Samsung A51 con Termux. Usa la librería `instagrapi` para evitar bloqueos. Ejecutar en Termux con Python 3.9+.  

```python
from instagrapi import Client
import time

# Configuración inicial
client = Client()
client.login("usuario_instagram", "contraseña_instagram")  # Reemplazar con credenciales

def publicar_historia(imagen_path, texto=""):
    client.story_upload(imagen_path, caption=texto)

def publicar_reel(video_path, caption=""):
    client.clip_upload(video_path, caption=caption)

def seguir_usuarios(usuarios):
    for usuario in usuarios:
        try:
            client.user_follow(client.user_id_from_username(usuario))
        except Exception as e:
            print(f"Error al seguir {usuario}: {e}")

def interactuar_gringo():
    feed = client.user_feed(client.user_id_from_username("gringo_usuario"))
    for media in feed:
        client.media_like(media.id)
        time.sleep(10)  # Evitar bloqueos

# Ejemplo de uso diario (ejecutar desde panel o Telegram)
if __name__ == "__main__":
    publicar_historia("/sdcard/bosio/historia.jpg", "🚧 Obra en progreso - Constructora JB")
    publicar_reel("/sdcard/bosio/reel.mp4", "Inversiones inteligentes con JB 🏗️💼")
    seguir_usuarios(["inversiones_vm", "tecnologia_arg", "fitness_vm"])
    interactuar_gringo()
```
